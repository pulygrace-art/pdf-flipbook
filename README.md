# PDF 翻頁書

上傳 PDF，在瀏覽器中以翻頁書的方式閱讀。PDF 只在瀏覽器本機處理，不會上傳到伺服器。

使用 [PDF.js](https://mozilla.github.io/pdf.js/) 轉換頁面、[StPageFlip](https://github.com/Nodlik/StPageFlip) 製作翻頁效果。

## 分享 PDF 給別人看

1. 到 GitHub repo 的 `books/` 資料夾，點 **Add file → Upload files**，把 PDF 拖進去後按 **Commit changes**。
2. 約 1 分鐘後，網站首頁的「書架」會出現這本書，按「複製分享連結」就能把網址傳給別人。

分享連結格式：`https://<帳號>.github.io/pdf-flipbook/?pdf=books/檔名.pdf`

> 注意：這個 repo 是公開的，放在 `books/` 裡的 PDF 任何人都能下載。
